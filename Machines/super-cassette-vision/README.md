# Super Cassette Vision

Sucesora de Cassette Vision, con una arquitectura renovada y gráficos basados en sprites.

- Fabricante: Epoch
- Primer lanzamiento mundial: 1984
- Motor candidato: EmuSCV
- Estado: documentación conservada; ficha excluida de la primera versión pública.

## Motivo

Pendiente de una fotografía reutilizable que identifique inequívocamente la variante francesa Yeno. La fotografía de museo disponible contiene varias máquinas y no permite certificar la identificación regional. La preferencia del proyecto es mostrar la versión europea cuando existe.

La ficha podrá incorporarse cuando se disponga de una fotografía europea verificable. No contiene juegos ni firmware propietario.
